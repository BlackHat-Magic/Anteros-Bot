## Overview

Anteros is a Discord bot that uses LLMs to respond to user queries. Basically, it turns Discord's UI into a ChatGPT interface.

### Goals

Originally, I just wanted to get comfortable with using the OpenAI API and LLMs. I also wanted to try my hand at deploying an LLM to Runpod. Now idk.

### Features

- Threads, regenerate, and undo
